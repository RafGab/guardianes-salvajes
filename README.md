# Guardianes Salvajes

Videojuego 3D (Three.js + Vite): héroes animales rescatan a personas y animales durante catástrofes naturales.

## Misiones
1. Inundación en Ciudad Ribera (agua que sube, corrientes, crecida repentina)
2. Incendio en el Bosque Ámbar (focos que se propagan, humo, calor)
3. Terremoto en Villa Roca (réplicas, escombros, grietas, calles bloqueadas)
4. Tormenta de hielo en Monte Blanco (ventisca, suelo helado, frío y hogueras)

## Héroes
Yagua (Tierra), Vorak (Fuego), Coral y Nerea (Agua), Aurora (Hielo), Ámbar (Aire).

## Ejecutar
    npm install
    npm run dev   # http://127.0.0.1:5180

## Modelos realistas (GLB)
Ver `public/models/README.txt`. Los `.glb` de `public/models/` sustituyen a los modelos procedurales.
